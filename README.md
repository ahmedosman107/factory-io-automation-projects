# Factory I/O Automation Projects ⚙️

A collection of industrial automation and PLC simulation tasks developed using **Factory I/O**, focusing on sensors, actuators, sequencing, material handling, sorting, and control logic.

## 🏭 Projects

### 1. Pivot Arm
Automation of a pivot-arm mechanism for controlling and redirecting objects within a production process.

**Main concepts:**  
PLC control • Sensors • Actuators • Sequential logic

---

### 2. Color Detection
Implementation of a color-based detection process for identifying objects moving through an automated system.

**Main concepts:**  
Color detection • Sensors • PLC logic • Industrial automation

---

### 3. Sorting by Color and Shape
Automated classification and sorting of objects based on their color and shape.

**Main concepts:**  
Object detection • Sorting logic • Sensors • Actuators • Conveyor control

---

### 4. Sorting Level 2
An advanced sorting task involving multiple stages of automated object handling and classification.

**Main concepts:**  
Sequential control • Sensors • Actuators • Sorting logic • Conveyor systems

---

### 5. Bottle Line
Simulation of an automated bottle-handling production line.

**Main concepts:**  
Conveyor systems • Sensors • Actuators • Sequential control • PLC programming

---

### 6. Elevator
Automation of an industrial elevator for transferring objects between different levels.

**Main concepts:**  
Position control • Sensors • Actuators • Sequential logic • Safety conditions

---

### 7. Left & Right Sort — Turntable
Automated sorting of objects to different directions using a rotating turntable mechanism.

**Main concepts:**  
Turntable control • Directional sorting • Sensors • Actuators • PLC logic

---

### 8. Double Colors
Automation task involving the detection and handling of objects based on multiple color conditions.

**Main concepts:**  
Color detection • Conditional logic • Sensors • Sorting • PLC programming

---

### 9. Elevator 2
An extended elevator automation task involving more advanced movement and control logic.

**Main concepts:**  
Position control • Sequential logic • Sensors • Actuators • PLC programming
